What only Cairn shows

  • It remembers. The sites Cairn collects from show only the present. Cairn keeps a record from every run, so it can tell a package stuck through several uploads, or merged and back again, and whether each board is shrinking.
  • It joins the boards. When a package is stuck in proposed and also needs a merge, each board links to the other's row, so you never look it up twice.
  • It shows what you are holding up. Britney lists a problem under the upload it blocks: a test failing on it, or another upload it has to wait for. Cairn also lists it under the package causing it, so the people who can fix it find out.
